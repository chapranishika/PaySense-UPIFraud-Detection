# Feature audit -- model benchmark (2026-08-27)

Every raw column in `paysense_master_dataset.csv` classified as VALID / SUSPICIOUS / INVALID / TARGET before any model in this benchmark was trained. "Constant in supplement" means the column takes exactly one value across all 10,000 supplement-source rows -- computed directly from the CSV, not assumed.
